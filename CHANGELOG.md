# Changelog

## [2.3.0] - 2026-07-18

### Added
- Focus timer with motivational quotes and configurable interval
- Daily time tracking per platform with 7-day bar chart
- Schedule feature (active hours + day selection)
- Dark/light theme toggle
- Support modal with help information
- Power toggle to pause all blocking
- Facebook: block Home feed, News Feed, Reels, Watch, Stories, Notifications
- TikTok: block For You feed, Following, Discover, Search, Notifications
- Instagram: block Feed, Reels, Explore, Suggested accounts, Notifications
- YouTube: block Home, Shorts, Recommendations, Sidebar, Comments, Autoplay, End screen, etc.
- Granular per-platform toggles for each blocked element
- Privacy-first design: all data stored locally
- Motivational reminders with quote overlays

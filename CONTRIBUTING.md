# Contributing to Reclaim Focus

Thank you for your interest! Here's how you can help.

## Reporting Issues

- Check existing issues before creating a new one.
- Use the bug report or feature request templates.
- Include your browser version and extension version.

## Development Setup

1. Clone the repo:
   ```bash
   git clone https://github.com/SoukoX/reclaim-focus.git
   cd reclaim-focus
   ```

2. Load the extension in Firefox via `about:debugging#/runtime/this-firefox`.

3. Make your changes and test them by reloading the extension.

## Code Style

- Match the existing code style (no semicolons, 2-space indentation).
- Test on all supported platforms before submitting.
- Keep the extension lightweight — no external dependencies.

## Pull Request Process

1. Fork the repo and create a feature branch.
2. Make your changes.
3. Test thoroughly.
4. Submit a PR with a clear description of what you changed and why.

### Commit Messages

Follow conventional commits:
- `feat:` — new feature
- `fix:` — bug fix
- `refactor:` — code restructuring
- `docs:` — documentation changes
- `style:` — formatting changes

## Code of Conduct

Be respectful and constructive. We're all here to make the web less distracting.

# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 2.x     | Yes       |
| < 2.0   | No        |

## Reporting a Vulnerability

This extension stores all data locally. No data is sent to any server.

If you discover a security vulnerability, please open an issue with the "bug" template. Do not disclose it publicly until it has been addressed.
